# Знак парафии и локализованное название — 30.10.2026

По последнему заданию владельца знак отделён от надписей. Один чистый SVG assets/brand/poroshkovo-parish-symbol.svg содержит только линии двух святых, нимбы, кресты, книгу и посох. Нет видимых букв, text, image, встроенного PNG или внешних зависимостей. Это кодовый вектор в характере выбранного владельцем минималистичного изображения, а не буквенный заменитель.

Название — три HTML-строки из content/brand.json, name_lines.uk/en: ПАРАФІЯ / СВЯТИХ КИРИЛА І МЕТОДІЯ / ПОРОШКОВО и PARISH OF / SAINTS CYRIL AND METHODIUS / POROSHKOVO. Header и Footer возвращают на главную текущего языка. На компьютере знак 64 px, на мобильном 52 px; SVG сохраняет чёткость HiDPI. Название переносится отдельно от знака; языковые кнопки и меню остаются доступными на 320 px.

Тот же знак без надписей используется в подвале, PNG 64/128/192/256/512, favicon ICO 16/32/48, PNG 16/32/48, Apple 180, icons 192/512. Два manifest сохраняют язык start_url. Пути имеют версию по SHA256 символа для обновления кеша. Светлая и тёмная темы проверяются media-qa. Социальные карточки og-card-uk.png и og-card-en.png локализованы отдельно; legacy og-card.png соответствует EN.

Предыдущий SVG с растровым украинским названием удалён из публичных ресурсов. Предыдущие логотипы и исходники сохранены вне публикации в photos/editorial_sources/before-localization-* и originals_readonly. Не изменять исторические документы и исходные имена файлов.

Проверки: npm run check; npm run test:localization; npm run test:media. Скриншоты попарного сравнения — audit/localization-*-proof.html. Автотест не заменяет просмотр фотографий на наличие букв в пикселях.
