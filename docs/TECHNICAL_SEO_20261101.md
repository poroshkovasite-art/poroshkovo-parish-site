# Техническая готовность к индексации — 01.11.2026

Независимый исходный HTTP-аудит обнаружил **17 украинских и 17 английских страниц**, все доступны и связаны внутренними HTML-ссылками. Проверены обычный клиент и Googlebot. Главный Sitemap и robots.txt отвечают HTTP 200; XML корректен. Перечень Sitemap уже совпадал с реальными публичными страницами, без технических адресов, редиректов и дублей. `lastmod` не добавляется: точных исторических дат обновления всех страниц нет. Сборка формирует маршруты и Sitemap автоматически из опубликованных страниц.

Self canonical, HTML lang, взаимные uk/en hreflang и x-default на соответствующую UA-страницу уже были правильными. Ни один из 34 публичных маршрутов не имел noindex/nofollow или блокирующего X-Robots-Tag. Title, description и H1 сохранены, пользовательские тексты не переписывались. Обе языковые версии отдаются напрямую, без переключения по User-Agent или языку браузера.

Найдены и исправлены:

1. На Home/Contacts не было JSON-LD прихода. Теперь общий Church / GeoCoordinates содержит новые координаты владельца, реальное имя, ссылку на карту, публичный телефон, греко-католическую идентификацию и епархию, населённый пункт/область/страну и существующий логотип. Неизвестные улица, индекс и email не добавлены. Свойства соответствуют [Schema.org Church](https://schema.org/Church); конфессия описывается подтверждённым текстом, не несуществующим свойством.
2. Реальная страница 404 уже возвращала статус 404 и noindex, но наследовала canonical/hreflang главной. Эти ссылки и Schema главной убраны из технической страницы ошибки. Действующие страницы сохраняют свои canonical/hreflang.

Новый аудит `scripts/seo-audit.py` использует стандартные XML/HTML-парсеры Python, независимо обнаруживает `dist/uk/**/index.html` и `dist/en/**/index.html`, сверяет их с manifest и Sitemap, обходит все реальные внутренние ссылки, проверяет метаданные и точность JSON-LD. Режим `--live` повторяет HTTP-проверки каждого адреса двумя User-Agent, включая три несуществующих адреса, Sitemap и robots. Блокировки, редиректы или неожиданный статус вызывают FAIL.

Команды:

```text
npm run build:production
npm run check
npm run test:seo
python scripts/seo-audit.py --live
```

Сырой исходный отчёт: внешний `audit/seo-baseline-verification.json`; локальный — `seo-local-verification.json`; финальный — `seo-production-verification.json`. Полный список абсолютных адресов, HTTP-статусы, title/H1/description, canonical/hreflang и Schema каждого адреса содержатся в JSON. Итоговый Markdown после публикации сохраняется во внешний `SEO_AUDIT_20261101.md` и в Desktop-резервную копию.

Наличие технической готовности не означает фактическую индексацию. Новые подтверждения из Google Search Console в этой задаче не получены. Файлы Google verification и meta-тег сохранены.
