`content/photos.json` хранит двуязычные title/caption/alt, права на публикацию согласно поручению владельца, исходный SHA256, реальные размеры и варианты WebP. `content/site.json` задаёт `hero_photo_id: divine-liturgy`. Фото не назначено портретом конкретного настоятеля. Дата, уже нанесённая на зимний снимок, сохранена как часть исходного изображения, но не используется как подтверждённая дата события в тексте или модели.

Веб-версии: `assets/photos/<id>-480.webp`, `-640.webp`, `-960.webp`, а также версия по реальной исходной ширине: 1122 px для литургии и благословения, 1086 px для группы, 1672 px для зимнего отдыха. Все исходные кадры и подготовленные подписи сохранены, генеративной обработки не было. Оригиналы и контактный лист находятся в отдельном рабочем фотоархиве.

Для шести NEF использована полноразмерная встроенная камерная JPEG-проявка 7360×4912, сохраняющая исходный баланс белого. Только лёгкое осветление тоновой кривой (gamma 0.94–0.985 по яркости кадра) и насыщенность ×1.025. Светлые наружные кадры изменены минимально; тёмные интерьеры стали немного светлее. Дополнительные варианты для NEF: 480/640/960/1920 px по ширине, без кадрирования, деформации, перерисовки или увеличения. EXIF/GPS в веб-файлы не переносятся. Исходные NEF скопированы без изменения байтов; SHA256 сохранены в реестре. Сравнение до/после — в контактном листе `nef-six-before-after.jpg` рабочего фотоархива.

## Логотип

Использован именно приложенный круглый чёрно-белый PNG, найденный на рабочем столе без суффикса `(1)`. Исходный SHA256: `03aac3fa6fe42999fd21228fc22c16e754bab29b0787056e7af99125ba5b72e8`. Неизменённая копия сохранена в `photos/originals_readonly/poroshkovo-parish-logo-original.png` вне публичного репозитория.

Техническое имя: `poroshkovo-parish-logo`. Официальное обозначение греко-католической парафии в текстах не менялось по исходному имени файла. Применены обычное монохромное преобразование и ресайз; прозрачным сделан только связанный с краями внешний белый фон. Внутренние белые элементы, лица, надпись и композиция сохранены. Нет новой символики или буквенного заменителя.

- Шапка: PNG 64, 128, 192, 256 px с srcset; отображение 60×60 px на компьютере, 44×44 px на мобильном.
- Favicon: корневой `favicon.ico` и `assets/favicon.ico`, кадры 16/32/48; дополнительные PNG 16, 32, 48.
- Телефон: `apple-touch-icon.png` 180, `icon-192.png`, `icon-512.png`.
- Manifests `/uk/site.webmanifest` и `/en/site.webmanifest` создаются сборкой; `start_url` сохраняет язык.
- Ссылки шапки, favicon и manifest имеют версию по хешу содержимого для обновления кеша.

Проверка: `npm run build:production`, `npm run check`, `npm run test:browser`, `npm run test:media`. После деплоя: `MEDIA_BASE_URL=https://poroshkovo.pages.dev npm run test:media` (в PowerShell задаётся через `$env:MEDIA_BASE_URL`). Проверяются действительные фото и иконки, выбранный hero, пропорции, Retina-источники, светлая/тёмная тема браузера, клавиатура/жесты галереи и корневой переход. Скриншот favicon — отдельный проверочный экран реальных файлов на светлом и тёмном фоне, не макет вкладки браузера.
