# poroshkovo-parish-site
Official website of Saints Cyril and Methodius Greek Catholic Parish, Poroshkovo, Ukraine

# Парафія святих Кирила і Мефодія · Порошково

Самостоятельный статический сайт на украинском и английском. Рабочая папка: `D:\POROSHKOVO_PARISH_WORK\site`. Никакой связи с инфраструктурой ISF или NAU. Репозиторий: `poroshkovasite-art/poroshkovo-parish-site`. Владелец разрешил публикацию существующего основания; фотографии и подтверждённые текущие сведения будут добавлены позже.

## Быстрый запуск

Требуется Node.js 20+.

```powershell
npm ci
npm run build
npm run check
npm run preview
```

Открыть `http://localhost:4173/uk/` или `http://localhost:4173/en/`. Для просмотра в Windows можно дважды щёлкнуть `START_SITE.cmd`: он пересобирает сайт и открывает браузер после запуска сервера. Окно сервера оставить открытым; Ctrl+C останавливает просмотр. Сборка не зависит от npm-пакетов; `npm ci` устанавливает только инструменты браузерной проверки. `dist/` — готовые статические файлы. Не открывать HTML двойным щелчком: абсолютные пути рассчитаны на HTTP-сервер.

Для Playwright:

```powershell
npx playwright install chromium
npm run test:browser
```

Можно использовать существующий Chrome через переменную `PLAYWRIGHT_CHROMIUM_EXECUTABLE` с полным путём к `chrome.exe`. Проверка работает с отдельным временным профилем браузера. Результаты — `../audit/`.

## Что уже подготовлено

22 двуязычные содержательные страницы: главная, о парафии, история, богослужения, духовная жизнь, община, катехизация, матери в молитве, контакты, фотогалерея, приватность. Плюс корневой переход и 404. Историческая шкала содержит 11 дат с фильтрами. Мобильное меню, выпадающие группы, карусель со стрелками/клавиатурой/жестами, переключение языка сохраняют маршрут. Содержимое читается без JavaScript; открытые группы меню работают через HTML `details`.

Галерея включена с десятью фотографиями, фильтрами и модальным просмотром. Компоненты EventCard, Schedule, TeamCard, Map и CTA готовы для дальнейшего наполнения. Новости и поддержка не выводятся в навигацию и не создаются как пустые страницы: они включаются после подтверждённых данных и заполнения их метаданных. Правила включения — в `scripts/build.mjs`; образцы записей — в `templates/`.

Владелец предоставил и разрешил опубликовать четыре подготовленных PNG и шесть NEF. Главная фотография обеих языковых версий — `divine-liturgy`, священник за престолом возле чаши. Галерея содержит все десять изображений. Храм и колокольня размещены в About; дети, зимний отдых и группа на ступенях — в Community; благословение, молитва у распятия, иконостас и престол — в Spiritual life. Оригиналы сохранены отдельно, WebP созданы без обрезки и увеличения. Для NEF применены только небольшое осветление и коррекция насыщенности. Имена людей и даты событий не добавлены.

В шапке установлен предоставленный владельцем официальный чёрно-белый круглый логотип Кирилла и Мефодия с надписью «ПАРОХІЯ ПОРОШКОВО». Версии 64–512 px сохраняют композицию и внутренний белый фон, внешний фон прозрачен. ICO 16/32/48, PNG favicon, Apple touch и телефонные иконки подключены с версионированием. Локализованные manifests сохраняют язык главной страницы. Материалы ISF не используются.

## Структура

- `content/` — UA/EN тексты, история, источники, расписание, люди, новости и фотокаталог.
- `scripts/components.mjs` — общие компоненты; `build.mjs` — генератор.
- `assets/` — собственные стили, JavaScript, favicon и типографическая OG-карточка.
- `templates/` — образцы записей для будущих материалов.
- `docs/` — обновление, источники, вопросы и будущая публикация.
- `public/` — дополнительные согласованные статические файлы.

Шрифты системные; внешних загрузок шрифтов, аналитики, cookies и форм нет. Публичная сборка не содержит служебного расписания, адреса из реестра, личных исходных путей, списка вопросов и реестра прав на фотографии.

## SEO и публикация

Локальная сборка (`npm run build`) намеренно имеет `noindex` и `robots.txt: Disallow: /`. Production-сборка (`npm run build:production`) включает индексацию и использует согласованный адрес `https://poroshkovo.pages.dev` в canonical/hreflang, sitemap и Open Graph. Уникальные заголовки, описания, SVG favicon и языковые пары созданы.

Параметры адреса и разрешение владельца записаны в `content/site.json`. Cloudflare Pages: проект строго `poroshkovo`, ветка `main`, build command `npm run build:production`, output directory `dist`, Node 22. Автоматический деплой настраивается через Git-интеграцию Cloudflare с этим репозиторием. Факт успешного выпуска подтверждается отдельным отчётом после проверки реального адреса. См. `docs/DEPLOYMENT.md`.
