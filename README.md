# Парафія святих Кирила і Мефодія · Порошково

Самостоятельный статический сайт на украинском и английском. Рабочая папка: `D:\POROSHKOVO_PARISH_WORK\site`. Никакой связи с инфраструктурой ISF или NAU. По указанию владельца от 29.10.2026 публикация отложена до передачи материалов и доступов.

## Быстрый запуск

Требуется Node.js 20+.

```powershell
npm ci
npm run build
npm run check
npm run preview
```

Открыть `http://localhost:4173/uk/` или `http://localhost:4173/en/`. Для просмотра в Windows можно дважды щёлкнуть `START_SITE.cmd`: он пересобирает сайт и открывает браузер после запуска сервера. Окно сервера оставить открытым; Ctrl+C останавливает просмотр. Сборка не зависит от npm-пакетов; `npm ci` устанавливает только инструменты браузерной проверки. `dist/` — готовые статические файлы. Не открывать HTML двойным щелчком: абсолютные пути рассчитаны на HTTP-сервер.

Для Playwright:

```powershell
npx playwright install chromium
npm run test:browser
```

Можно использовать существующий Chrome через переменную `PLAYWRIGHT_CHROMIUM_EXECUTABLE` с полным путём к `chrome.exe`. Проверка работает с отдельным временным профилем браузера. Результаты — `../audit/`.

## Что уже подготовлено

20 двуязычных содержательных страниц: главная, о парафии, история, богослужения, духовная жизнь, община, катехизация, матери в молитве, контакты, приватность. Плюс корневой переход и 404. Историческая шкала содержит 11 дат с фильтрами. Мобильное меню, выпадающие группы, карусель со стрелками/клавиатурой/жестами, переключение языка сохраняют маршрут. Содержимое читается без JavaScript; открытые группы меню работают через HTML `details`.

Компоненты Gallery, EventCard, Schedule, TeamCard, Map и CTA готовы для дальнейшего наполнения. Новости, галерея и поддержка не выводятся в навигацию и не создаются как пустые страницы: они включаются после подтверждённых данных и заполнения их метаданных. Правила включения — в `scripts/build.mjs`; образцы записей — в `templates/`.

Фото пока не предоставлены. Главная использует самостоятельную типографическую композицию с историческими датами. Знак «П» и Open Graph-карточка — нейтральное рабочее оформление, не утверждённый логотип или герб. Внешние фото, изображения детей и материалы ISF не используются.

## Структура

- `content/` — UA/EN тексты, история, источники, расписание, люди, новости и фотокаталог.
- `scripts/components.mjs` — общие компоненты; `build.mjs` — генератор.
- `assets/` — собственные стили, JavaScript, favicon и типографическая OG-карточка.
- `templates/` — образцы записей для будущих материалов.
- `docs/` — обновление, источники, вопросы и будущая публикация.
- `public/` — дополнительные согласованные статические файлы.

Шрифты системные; внешних загрузок шрифтов, аналитики, cookies и форм нет. Публичная сборка не содержит служебного расписания, адреса из реестра, личных исходных путей, списка вопросов и реестра прав на фотографии.

## SEO и публикация

Локальная сборка намеренно имеет `noindex` и `robots.txt: Disallow: /`. Canonical/hreflang и sitemap используют только локальный адрес, пока новый реальный адрес не согласован. Уникальные заголовки, описания, OG, SVG favicon и языковые пары уже созданы.

Для будущего выпуска заполнить `content/site.json`: `production_url` — реальный новый HTTPS-адрес, `publication_approved: true` — только после согласования. Затем `node scripts/build.mjs --production` и проверки. Пока ничего не зарегистрировано и не опубликовано. См. `docs/DEPLOYMENT.md`.
